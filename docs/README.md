# ペットシッター 空き状況ページ

お客さんにリンクを送るだけで、空き状況を見てもらえるページです（サーバー不要）。

| ファイル | 役割 |
|---|---|
| `index.html` / `client.css` | お客さん用ページ（英語。このURLを送る） |
| `admin.html` / `style.css` | 自分用の管理ページ（日本語） |
| `data.json` | 空き状況のデータ（管理ページから更新） |
| `common.js` / `nlp.js` | 共通の処理／話した言葉の読み取り |
| `art.js` / `seasons.js` | 猫と犬の線画、季節の飾り |

## 表示のしかた
何も入れていない日は **○ 空き**。変えたい日だけ入れます。

- **△ 一部OK**（ひとことメモ付き。例：Drop-in visits only / Mornings only / Please ask）
- **× 埋まり**
- **Off お休み**

料金や件数、サービスの細かい決まりは表示しません。お客さんは日付を2回タップすると、その期間の空きをまとめて確認できます。

## 話して入れる
管理ページの 🎤 で話すか文字で入れて「読み取る」→ 確認して「これで反映」。

| 言い方の例 | 結果 |
|---|---|
| 20日から25日はドロップオフしか受けられない | △ Drop-in visits only |
| 10日から12日は埋まった／予約入った | × |
| 12/1は休み・28日から1月3日は旅行 | Off |
| 15日は午前だけ／明日は夕方は行けない | △ Mornings only／Not available in the evening |
| 28日は要相談 | △ Please ask |
| 19日は小型犬なら預かれる（決まった言い方以外） | △ そのままメモにして英訳 |
| 20日から25日は元に戻して／空いてる | ○ に戻す |

英訳は、管理ページの「自動翻訳の設定」にClaude APIキーを入れておくと自動で行います。キーがなくても、一覧から英語を手で入れられます（未入力の間は「Limited availability, please ask」と表示）。

## 季節の飾り
トップは月ごとに飾りと色が変わります（1月 雪／2月 バレンタイン／3月 クローバー／4月 春の雨／5月 花／6月 夏／7月 独立記念日／
8月 夏の海／9月 初秋／10月 ハロウィン／11月 感謝祭／12月 クリスマス）。`index.html?month=12` で好きな月を確認できます。

## 公開のしかた（GitHub Pages）
1. リポジトリの Settings → Pages で、公開するブランチと `/docs` フォルダを選ぶ
2. `https://<ユーザー名>.github.io/<リポジトリ名>/` がお客さん用、`.../admin.html` が管理ページ
3. 管理ページの「GitHub保存の設定」に Fine-grained token（Contents: Read and write）を入れると「公開する」で更新できます

`data.json` は誰でも見られます。メモにお客さんの名前・住所・料金は書かないでください。
