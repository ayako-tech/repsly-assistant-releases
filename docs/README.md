# ペットシッター 空き状況カレンダー

お客さんにリンクを送るだけで空き状況を見てもらえる、サーバー不要のページです。

| ファイル | 役割 |
|---|---|
| `index.html` | お客さん用ページ（このURLを送る） |
| `admin.html` | 自分用の管理ページ（予定・お休み・設定の編集） |
| `data.json` | 空き状況のデータ（管理ページから更新） |

## 対応しているサービス
- **お泊まりシッター**：お客さん宅に泊まる。1晩に受けられる数を設定（通常1）
- **お預かり**：自宅で預かる。1晩に受けられる組数を設定
- **訪問シッター**：朝・昼・夕など時間帯ごとに、回れる件数を設定（1日1回・2回の訪問に対応）
- 「お泊まりとお預かりは同じ夜に受けない」設定あり（初期設定はON）
- お休みの期間、毎週の定休日

## 公開のしかた（GitHub Pages・無料）
1. このリポジトリの Settings → Pages で、Source を「Deploy from a branch」、
   ブランチとフォルダ `/docs` を選んで保存
2. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。これをお客さんに送ります
3. 管理ページは `.../admin.html`

> GitHub Pages を無料プランで使うにはリポジトリが公開（Public）である必要があります。
> `data.json` の中身は誰でも見られるので、メモ欄にお客さんの名前や住所は書かないでください。

## 管理ページから「公開する」ボタンで保存するには
1. GitHub → Settings → Developer settings → Fine-grained tokens でトークンを作成
   （対象リポジトリだけ、権限は Contents: Read and write）
2. 管理ページの「GitHub保存の設定」にオーナー名・リポジトリ名・ブランチ・`docs/data.json`・トークンを入れて保存
   （トークンはその端末のブラウザの中だけに保存されます）

トークンを使わない場合は「データをダウンロード」して、`docs/data.json` を差し替えてください。
